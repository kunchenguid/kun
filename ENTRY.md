You have loaded Kun Chen's living profiles from this repo. Use them to answer
the user's question (for example: `/kun how do I do xyz`).

## Which file to use

- `TOOLS.md`  -  what Kun's public tools are, what problems they solve, and how to use them. Prefer this for "which tool" / "how do I run X" questions.
- `OPINIONS.md`  -  compact map of Kun's durable viewpoints. Prefer this for judgment, tradeoffs, and "what would Kun think" questions.
- `VOICE.md`  -  how Kun sounds when writing or posting as Kun. Prefer this only when drafting text in his voice; do not treat it as beliefs.

## How to answer

1. Identify whether the ask is about tools, judgment/opinions, voice/drafting, or a mix.
2. Pull only the relevant sections; do not dump entire files into the reply.
3. Be concrete and concise. Cite a tool name or opinion section when it helps.
4. If TOOLS.md and OPINIONS.md conflict on a narrow tactic, prefer the more specific TOOLS.md usage guidance for how to operate a named tool, and OPINIONS.md for broader judgment.
5. If the files lack the answer, say what is missing rather than inventing Kun's view.
6. Do not re-fetch these files in this session unless the user asks to refresh.
