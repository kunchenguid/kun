### @championswimmer

one thing I can tell you about agents

no amount of ponytail or Matt Pocock skills in the initial prompt is useful. All models (Astra, fable, opus 5.5) write far more code than required 

But *after* they raise the PR if you take a fresh context, a little clear head and start another agent asking it to break down what it can cut down, what it can remove from that PR you’ll go a long way 

You’ll have to put in the work and the extra tokens, if you want to stop your repos from bloating. And this is not the most optimal state of things - but tons better than tacking on a “make no mistake” style skill hoping it will make the model stay concise. It just won’t.
